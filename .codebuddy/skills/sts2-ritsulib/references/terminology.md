# 术语表

| 英文术语 | 中文 | 用法 |
|---------|------|------|
| settings UI | 设置界面 | Mod 配置的整体界面 |
| page | 页面 | 设置界面中的单个注册页面 |
| section | 分区 | 页面中的结构化分组 |
| entry | 条目 | 分区中的一个可见行/控件 |
| binding | 绑定 | UI 与存储状态之间的读写链接 |
| persistence | 持久化 | 存储层与存档生命周期 |
| persisted | 已持久化 | 通过持久化层写入的值 |
| preview-only | 仅预览 | 永不持久化数据的控件 |
| fallback | 回退 | 兼容性或数据缺失时的行为 |
| compatibility fallback | 兼容回退 | 原版不完整时的窄范围行为 |
| bridge patch | 桥接补丁 | 将 Mod 内容转发到原版逻辑的补丁 |
| registry | 注册器 | 内容类型的运行时注册容器 |
| content pack | 内容包 | 写入多个注册器的便捷入口 |
| builder | 构建器 | 流式页面/分区/内容构建 API |
| override | 覆写 | 替换资源路径、行为或值来源 |
| placeholder | 占位值 | 数据缺失时的临时回退值 |
| scope | 作用域 | 持久化值的存储作用域 |
| profile | 档位 | 每档案的存档作用域 |
| global | 全局 | 跨档案的存档作用域 |
| epoch | 纪元 (Epoch) | 游戏术语 - 保留英文 |
| story | 故事 (Story) | 游戏术语 - 保留英文 |
| Ancient dialogue | Ancient 对话 | 游戏系统及相关键 |

# 框架设计原则

1. **显式注册** - 无魔法发现；所有内容通过清晰的 API 注册
2. **固定标识** - `ModelId.Entry` 是确定性的：`<MODID>_<CATEGORY>_<TYPENAME>`
3. **资源配置** - 结构化记录而非大型角色基类
4. **场景替换** - 非就地修改原版资源
5. **窄范围兼容** - 仅在基础游戏没有安全扩展点时进行桥接
6. **先注册后使用** - 所有注册在早期启动期间冻结
7. **基于类的持久化** - 支持模式版本控制、迁移、安全序列化
